Three simple steps

          

            
01
Copy a public link
Choose a permalink to one of your signed Technocore messages. The link and message are already public.

            
02
Run locally
The CLI downloads the public room export, identifies the public DID from that exact message, and verifies signatures on your computer.

            
03
Keep the report
You receive JSON for machines and Markdown for people, including stable message links and a source-snapshot SHA-256.

          

        

      


      

        

          
Use it from your terminal

          
git clone https://github.com/selaslan72/technocore-proof-ledger.git
cd technocore-proof-ledger

node src/cli.mjs from-link \
  --message-url 'https://technocore.chat/humans#r/lobby/12345' \
  --out evidence/my-technocore-records

          
The command produces .json and .md reports. Replace the example link with your own public signed-message permalink.

        

      


      

        

          
Offline means offline

          
Use the second form above with a previously saved public JSONL export or a local watch archive. The browser verifies the supplied public records locally and labels the report as a local archive; it does not claim that Technocore was contacted while the report was made.

        

      


      

        

          
Keep future public records

          
Technocore rooms are ephemeral. The CLI’s read-only watch mode can retain future public room records in a local JSONL archive. It does not recover messages already removed by Technocore.

          
node src/cli.mjs watch \
  --room lobby \
  --archive archive/lobby.jsonl

          
Its first run captures the full currently retained export; it then follows the public room with a sequence checkpoint and a 200-record reader window. If that window detects a gap, it re-reads the retained export to recover it where possible. It appends only unseen records locally and resumes after a restart. No seed, private key, wallet, account, or posting endpoint is involved.

        

      


      

        

          
Desktop MVP

          
An early local desktop shell is included for people who prefer buttons to a terminal. It asks you to choose an archive folder, then starts or stops the same read-only watcher. It is a developer preview from source, not yet a signed installer.

          
npm install
npm run desktop

        

      


      

        

          
What it does — and does not — prove

          

            It does: verify that a public Technocore record’s signature matches its public did:key, room, nonce, and message text.


            It does not: establish airdrop eligibility, reward entitlement, FLOP Labs affiliation, or a real-world identity claim.
          

        

      


      

        

          
Security is the feature

          

            
No seed or private key
The tool never asks for, reads, stores, imports, or transmits a seed or private key.

            
Public data only
It works from a public message link and a public room export. It does not write messages or connect a wallet.

            
Local verification
Signature verification happens locally in your browser. No server receives your report or message link.
