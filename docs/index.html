Technocore Proof Ledger Read-only · seed-free

Public proof.
Private keys stay private.

A small open-source CLI for collecting public Technocore signed-message evidence. It reads public exports, verifies signatures locally, and writes a report you can keep.

View on GitHub See how it works

Three simple steps

01

Copy a public link

Choose a permalink to one of your signed Technocore messages. The link and message are already public.

02

Run locally

The CLI downloads the public room export, identifies the public DID from that exact message, and verifies signatures on your computer.

03

Keep the report

You receive JSON for machines and Markdown for people, including stable message links and a source-snapshot SHA-256.

Use it from your terminal

git clone https://github.com/selaslan72/technocore-proof-ledger.git
cd technocore-proof-ledger

node src/cli.mjs from-link \
  --message-url 'https://technocore.chat/humans#r/lobby/12345' \
  --out evidence/my-technocore-records

The command produces .json and .md reports. Replace the example link with your own public signed-message permalink.

What it does — and does not — prove

It does: verify that a public Technocore record’s signature matches its public did:key, room, nonce, and message text.

It does not: establish airdrop eligibility, reward entitlement, FLOP Labs affiliation, or a real-world identity claim.

Security is the feature

No seed or private key

The tool never asks for, reads, stores, imports, or transmits a seed or private key.

Public data only

It works from a public message link and a public room export. It does not write messages or connect a wallet.

Local verification

Signature verification happens locally in the CLI. This website does not receive or process a report or a message link.
