# Example output only

`technocore-proof.json` and `technocore-proof.md` are public demonstration outputs generated by this CLI from a public Technocore room export.

They show the report format and link-only workflow. They do **not** establish identity ownership beyond the record data, airdrop eligibility, reward entitlement, or any affiliation with FLOP Labs.

The directory is intentionally allow-listed in `.gitignore`; routine local reports should remain untracked unless a maintainer deliberately chooses to publish a clearly labelled example.
